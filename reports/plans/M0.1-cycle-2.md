## Ready-made solutions considered (DoD-6)

| Component | Considered | Verdict |
| --- | --- | --- |
| Empty files with a secret name | gitleaks (skips empty files: no content, no finding, even for path-only rules); trufflehog, detect-secrets (content scanners, same gap); GitHub push protection (content only) | **One line in `gitleaks.sh`**: `git ls-tree` (tree) / `git log --name-only` (each commit of the range) piped into `grep -P` with the name regex. Owner decision (above). No scanning of content: gitleaks still does all of that. |
| `.env*` names | gitleaks path rule | gitleaks: `\.env[^/]*` any case in `.gitleaks-strict.toml`, allowlist `.env.example` (unchanged). Same regex in the shell line. |
| Network guard (`conftest.py` `_install_network_guard`) | **pytest-socket** 0.8.1 (`--disable-socket --allow-unix-socket`); pytest-recording/vcrpy (HTTP only); keep own guard | **pytest-socket**, pinned `==0.8.1`, in `addopts`. It blocks creation of any non-Unix socket, so UDP `sendto` and IPv6 fail too. The own guard (~30 lines) is deleted. |
| Batch of secret fixtures | one gitleaks run per fixture repo | One repo with every history-free positive case, one `tree` + one `range` scan, assert every expected `File:` line. Repos only for cases that need history or a clean result. |
| mutmut test selection | `tests_dir` (deprecated in 3.8.1) | `pytest_add_cli_args_test_selection` (mutmut's replacement). |
| Keyword tables of `schema_lock.py` | mutmut (does not mutate module-level constants) | One test with `required` under every listed keyword, asserting `required_map` pointers. |
