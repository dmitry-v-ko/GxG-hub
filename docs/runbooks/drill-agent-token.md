# Учебная тревога 2: отзыв токена агента (AC-M14-05)

Сценарий: токен агента `t-pilot` (ContextForge) утёк или агент скомпрометирован (SEC-02). Нужно, чтобы старый токен перестал работать, а агент получил новый. Токен хранится в сервисе-хранилище `pilot-agent` (`PILOT_AGENT_TOKEN`, AS-28 `agent_token`); значения нигде не печатаются. Ведущий и дежурный — как в [первом учении](drill-effects-block.md).

**Подготовка.** `RAILWAY_TOKEN` оператора, доступ к репозиторию, `uv sync`. Токен агента, который «утёк», — текущий; ведущий фиксирует, что `scripts/deploy/pilot_agent.py probe` сейчас показывает список tools (`tools/list`).

## Шаги

1. **Остановить эффекты на время разбора** — шаг 2 [первого учения](drill-effects-block.md) (`switch set --scope global`). Утёкший токен всё равно может **читать**; блок эффектов закрывает запись.
2. **Выпустить новый токен:**
   ```bash
   RAILWAY_TOKEN=... uv run python scripts/deploy/pilot_agent.py setup
   ```
   Задача внутри Railway создаёт новый токен агента `agent-t-pilot-pilot-<время>`, кладёт его запечатанным в `pilot-agent.PILOT_AGENT_TOKEN`, ничего не печатает. Выход: `tool …`, `team …`.
3. **Отозвать все старые токены агента** (остаётся самый новый):
   ```bash
   RAILWAY_TOKEN=... uv run python scripts/deploy/pilot_agent.py revoke
   ```
   Ожидаемо: `agent tokens: [старый, новый]`, `revoke <старый> … -> 200|204`, `kept <новый>`.
4. **Проверить отзыв.** Запрос со старым токеном даёт 401 не позже чем через минуту (`AUTH_CACHE_REVOCATION_TTL` = 5 с, AC-M13-03). Старое значение у ведущего есть только в сценарии учения (тестовый токен); настоящий утёкший токен не вводить. Новым токеном `pilot_agent.py probe` показывает `tools/list`.
5. **Снять блокировку** (`switch clear`), если не ищется дальше причина компрометации.
6. **Если утечка шире** (токен лежал в логе или репозитории): ротация ключей — [approval-ops §2](approval-ops.md#2-ротация-ключа-execution-token-as-09-as-10) и смена секретов `GXG_SECRET__*` соответствующего сервиса.

## Критерий и что записывает ведущий

Старый токен отклоняется (401) ≤ 1 мин после шага 3; новый работает; блок эффектов не снимался до проверки. Время до блокировки эффектов (шаг 1) ≤ 5 мин, как в первом учении. Протокол заполняет человек.
