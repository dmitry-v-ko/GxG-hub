# Переход от GxG Agents V2

Подход: **strangler migration** — работающие сервисы остаются работающими, а новый Gateway подключает их поверх существующих контрактов.

1. **Инвентаризация:** зафиксировать владельца данных, хранилище секретов, runtime и внешние потребители для Knowledge Base, Voice/Oscar, Signal Intelligence, Telegram.
2. **Knowledge:** сохранить текущий KB в прежнем runtime, подключить read-only MCP facade к ContextForge. Не делать новую копию источника правды.
3. **Telegram:** подключить существующий Telegram adapter с проверкой разрешённых чатов; отдельно проверить пользовательскую сессию и секреты.
4. **Signals:** выделить минимум читающих операций как самостоятельный контракт; старый Mastra workflow продолжает работать, пока новый контракт не протестирован.
5. **Voice:** голосовой агент — независимый потребитель / исполнитель, не обязан проходить через MCP для realtime-audio. Подключать лишь нужные ему tools.
6. **Effects:** отдельно добавить политику и подтверждения для записи в CRM, отправки сообщений или публикации.
7. **A2A:** после MCP-first PoC; интегрировать самостоятельных агентов как исполнителей без автоматической передачи всех их прав.
8. **Вывод старого Hub:** только после параллельной проверки результатов, конфигурации прав, backout-плана и подтверждения, что старые consumers переведены.

Не переписывать старые базы данных, не отключать сервисы и не удалять миграции заранее. Любую production-миграцию и доступ к секретам согласовывать отдельно.

## Contract-first decision (2026-11-20)

До физического переноса сервисов следовать [Connector Contract](specs/mcp-connector-contract-v1.md) и [Service Integration](specs/service-integration-v1.md). Knowledge MCP уже существует: провести аудит и при необходимости тонкий wrapper. Signal Intelligence **не заменять одним MCP-сервисом**: он остаётся доменным оркестратором и использует ContextForge на стороне сбора источников и на стороне actions; доменные записи, lease и outcome не переносятся в Gateway. Во время cutover одному ActionCandidate соответствует только один авторитетный исполнитель, особенно для эффектов. Генератор MCP и конformance suite ещё не написаны.
