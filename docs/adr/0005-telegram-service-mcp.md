# ADR-0005: Telegram-коннектор — отдельный сервис и MCP-сервер по MCC за ContextForge

**Статус:** Accepted — решение владельца, 2026-11-22. Заменяет [ADR-0004](0004-telegram-connector-service.md).

## Решение

Это следствие гексагональной архитектуры, а не выбор между вариантами.

`dmitry-v-ko/gxg-telegram-service` — отдельный сервис с отдельным репозиторием и деплоем. Он единственный владеет:
- Telegram-сессией (Pyrofork, перенос из `gxg_agents_v2/telegram_ingest`);
- архивом и archive-sync;
- flood-wait и секретами.

Сервис сам является MCP-сервером по [MCP Connector Contract](../specs/mcp-connector-contract-v1.md) за ContextForge. Отдельного адаптера в Hub нет, прямого чтения его базы из Hub нет.

## Доступ

- **Что:** видимость tools — через RBAC и `unified_pdp` ContextForge; `*.execute` агентам запрещён всегда | **Зачем:** агент видит только свои tools | **Почему:** иначе агент вызовет внутренний `execute` в обход согласования.
- **Что:** чаты — через grants: RID `telegram:<connection>/chat/<chat_ref>`, проверка до чтения и до отправки | **Зачем:** изоляция чатов и tenant'ов | **Почему:** иначе любой агент читает и пишет в любой чат аккаунта.
- **Что:** запись проходит цепочку `telegram.message.propose` → политика или approver → Executor → `execute` с execution token, ключ провайдера = `intent_id` | **Зачем:** ни одно сообщение не уходит без политики и согласования | **Почему:** иначе обманутый агент пишет от аккаунта владельца.
- **Что:** Mastra из `gxg_agents_v2` ходит в Telegram только через Hub, как агент со своим principal | **Зачем:** один вход, одни права и один аудит | **Почему:** иначе у Mastra есть обходной путь мимо политики, и сессией владеют двое.

## Последствия

- Коннектор `connectors/telegram` из M11 (чтение базы архива) удаляется после M11.1. Проверки AC-M11-01…05 переносятся на сервис.
- Сервис зависит от `gxg-connector-kit` через git-зависимость с закреплённым commit; обновление кита — осознанный bump.
- Схема архива — внутренняя деталь сервиса. Проверка дрейфа схемы из ADR-0004 больше не нужна.
